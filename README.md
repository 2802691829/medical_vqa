# Medical VQA 毕业设计资料

本仓库用于归档医疗视觉问答（Medical Visual Question Answering）毕业设计相关资料，包括论文过程文件、答辩材料、演示视频、展示文稿及辅助处理脚本。

## 目录说明

| 路径 | 内容 |
| --- | --- |
| `答辩/` | 答辩 PPT、演讲稿、问答稿和演示视频 |
| `人智222-208221335-周健-王青云-pdf/` | 毕业设计过程材料的 PDF 版本 |
| `人智222-208221335-周健-王青云-word/` | 毕业设计过程材料的 Word 版本 |
| `outputs/` | 答辩文稿、预览图、构建清单及相关输出 |
| `*.py` | 文档整理、批量处理、校验和打包辅助脚本 |

## 主要资料

- 毕业论文终稿及过程文档
- 医疗视觉问答系统答辩演示文稿
- 配套演讲稿和教师提问应答稿
- 项目演示视频
- 展示文稿生成与校验所需的源文件

## 使用说明

1. 查阅论文时，优先进入 PDF 或 Word 资料目录。
2. 查看答辩成果时，进入 `答辩/` 目录。
3. `outputs/` 中保留了不同版本的展示文稿、预览图和生成记录，便于追溯与再次编辑。
4. Python 脚本主要用于原始文档的整理和校验；运行前请根据脚本导入项自行准备相应环境。

> 本仓库以毕业设计资料归档为主，不保证所有历史生成脚本可在任意环境中直接运行。
